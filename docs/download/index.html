Install on Android

  1. Tap Download Ony above. It opens in Chrome, even if you opened this page inside another app. If Android asks, allow Chrome to install apps.
  2. Chrome will warn "File might be harmful" and ask you to confirm. Tap Download anyway. It says that for every new version because that exact file is still new to Google; the APK is built by Ony's own release pipeline and signed with its release key.
  3. When the download finishes, open the APK and tap Install.
  4. Updating keeps your settings.

Download stuck at 100%? If you opened this link inside another app (WhatsApp, GitHub, Telegram, etc.), its in-app browser may not finish APK downloads. Open this page in Chrome and tap Download again.

Get it on your phone

  1. Open https://rohiitgit.github.io/ony/download/ on your Android phone, or send yourself this link.
  2. Tap Download Ony and install the APK.
